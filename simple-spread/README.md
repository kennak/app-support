# SimpleSpread

AUv3 Mono-to-Stereo Spread Effect Plugin for macOS and iOS

---

## Overview

SimpleSpread turns a mono source into a wide stereo image, and widens a stereo source.  
Choose one of six spread types, then fine-tune the amount of spread and the position in the stereo field.

---

## Parameters

### Type

| Type | Description |
|------|-------------|
| Centered | Spread image centered in the stereo field |
| Wide Centered | Wider spread image centered in the stereo field |
| Tight Stereo | Narrow stereo image |
| Wide Stereo | Broad stereo image |
| L panned | Spread image leaning to the left |
| R Panned | Spread image leaning to the right |

### Controls

| Parameter | Range | Default | Description |
|-----------|-------|---------|-------------|
| Input Gain | -45 – 6 dB | -3 dB | Input level |
| Spread | 0 – 100 % | 100 % | Amount of spread |
| Pan | L50 – C – R50 | C | Position in the stereo field |

---

## Compatibility

- macOS 13 or later
- iOS 16 or later
- AUv3 compatible: Logic Pro, GarageBand

## 概要

SimpleSpreadは、モノラル音源を広がりのあるステレオ音像に変え、ステレオ音源の広がりをさらに強調するプラグインです。  
6種類のスプレッドタイプから選び、広がりの量とステレオ上の位置を調整できます。

---

## パラメータ

### タイプ

| タイプ | 説明 |
|--------|------|
| Centered | 中央に定位する広がり |
| Wide Centered | 中央に定位するより広い広がり |
| Tight Stereo | 狭めのステレオ音像 |
| Wide Stereo | 広いステレオ音像 |
| L panned | 左に寄った広がり |
| R Panned | 右に寄った広がり |

### コントロール

| パラメータ | 範囲 | 初期値 | 説明 |
|----------|------|--------|------|
| Input Gain | -45 – 6 dB | -3 dB | 入力レベル |
| Spread | 0 – 100 % | 100 % | 広がりの量 |
| Pan | L50 – C – R50 | C | ステレオ上の位置 |
